# 小丸闲鱼管家

闲鱼多店铺管理桌面客户端：多店铺客服工作台、关键词自动回复、AI 兜底回复、虚拟商品自动发货、商品管理与 AI 文案、数据看板。

**本地运行，软件功能永久免费。** 自选 AI、API 取卡或通知服务可能另行收费；启用时相关内容会发送到你配置的服务。

> ⚠️ 本项目**不是原创开发的产品**，由社区开源项目与公开技术方案整合而成。使用前请阅读[免责声明](#免责声明与开源声明)。

## v1.2.1 修复

- 备份包含实际图片目录，导入前保存当前数据；导入后停止旧任务和写盘，重启不会覆盖恢复结果。恢复的店铺先停用并清除旧登录态，请重启后逐店铺启用并重新扫码登录。
- 发货、评价与收花必须核对平台结果；未确认时明确提示待核对，不按弹窗关闭判成功。
- 发货保留订单买家身份，可从已关联会话补全；启用了身份或信用风控却缺少所需数据时暂停发货，等待人工核对。
- 买家互动使用独立的永久动作状态防止并发、重启及日志轮换后重复执行；延迟设置生效，结果不确定时不自动重试。
- 自动收花接入订单页赠花按钮扫描；补齐“交易完成”状态，等待确认收货的订单不会提前互动。
- 未变化的待发货订单也会定期重检，兜底扫描支持本店和全局规则。

以上经过隔离回归及本地界面验证；真实店铺的页面选择器和交易结果仍需实测。

## v1.2.0 更新：订单 / 发货风控 / 买家互动 / 消息中心

这一版补齐了同类工具里最实用的卖家侧能力，并修掉几个「界面上有、实际没跑通」的问题。

**新增**

- **订单真实同步**：开启后常驻官方订单页，全量读取可见订单（不只待发货），入库买家、金额、数量、规格与状态；支持导出 CSV、订单备注、按店铺筛选。
- **卡密库**：独立卡密管理页，支持卡券分组、跨店铺查看、按状态筛选、批量删除。
- **三级发货规则**：全局默认 / 本店默认 / 指定商品，优先级由具体到通用；支持按 SKU 绑定不同卡密来源。
- **多数量发货**：买家拍 N 件就依次发 N 份卡密；发到一半失败整体判为待核对，不会只发一部分。
- **发货前风控**：买家黑名单、买家本店有未完成订单、跨店铺有未完成订单、买家信用过低；命中即拦截并留记录。
- **默认回复 / 商品专属回复 / 消息过滤**：默认回复可设「每个会话只回一次」；商品专属回复优先于关键词；过滤词命中的消息直接忽略。
- **买家互动**：收货致谢、索要小红花、自动评价、自动收花，全部逐账号开关且**默认关闭**，每单每项只执行一次。
- **消息中心**：跨店铺会话列表、回复决策日志（可查「为什么回 / 为什么没回」）、过滤词管理。
- **数据备份**：一键导出 / 导入（state.json + 聊天记录 + 图片素材），导入前自动保护现有数据。

**修复**

- 擦亮任务改为在**商品管理页**执行、评价任务改为在**订单页**执行（此前统一发到聊天页，必然找不到按钮）。
- 客户「拉黑」真正生效：拉黑买家不再自动回复，也不再自动发货。
- 自动发货可以真正更新平台订单状态（在订单页点发货并核对结果），不再是占位实现。
- 订单状态为「交易完成」时操作按钮显示「补发」而不是「发货」。
- 提示条移到右下角，不再遮挡页面顶部的同步 / 导出按钮；设置侧栏与表格滚动条不再挤压内容。

## v1.1.1 更新：商品同步修复

- 不再把官方个人主页的推荐位商品误当成本店商品，避免覆盖本地商品列表。
- 商品数量与列表异步加载时，不再把加载中的空白判为「暂无商品」并清空本地记录；只有确认数量加载完成且列表确实为空才视为空店铺。
- 官方在某个分类商品数为 0 时会隐藏数字，现按 0 正确解析，不再判定同步失败。
- 同步过程中登录失效或页面切到其他账号时立即中止，保留已有商品并提示重新登录。
- 商品数量非零但列表读取失败时明确报错，不伪报零商品。

| 卡密库 | 卡券分组、跨店铺库存、状态筛选、批量导入导出 |
| 订单管理 | 官方订单页全量同步、金额 / 数量 / 规格 / 备注、CSV 导出、发货与补发 |

| 多客服协作 | 会话分配、人工接管抑制自动回复 |
| 远程协作 | 局域网浏览器查看会话、回复、编辑商品，三级权限 |

## 技术路线

Electron 壳 + 内置浏览器加载**闲鱼官方网页** + preload 注入。

- 登录由你在官方页面扫码完成，软件**不代存账号密码**
- 消息读取与发送通过页面 DOM 交互实现，**不破解 IM 协议、不调用平台私有签名接口**
- 业务数据主要保存在本机；启用 AI、外部通知、API 取卡或远程协作时，相关内容按配置传输

## 从源码运行

```bash

```

```bash
npm run dist
```

## 项目结构

```
src/
├─ main/       主进程：多店铺视图、IPC、托盘、存储、自动发货、AI
├─ inject/     注入官方页面的 preload：消息抽取、发送、商品扫描
├─ shell/      本地界面：渲染层、表格、图表、对话框
└─ remote/     局域网远程协作的浏览器端
scripts/       构建与验证脚本
tests/         单元与回归测试
```
