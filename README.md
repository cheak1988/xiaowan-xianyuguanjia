# 小丸闲鱼管家

闲鱼多店铺管理桌面客户端：多店铺客服工作台、关键词自动回复、AI 兜底回复、虚拟商品自动发货、商品管理与 AI 文案、数据看板。

**本地运行，软件功能永久免费。** 自选 AI、API 取卡或通知服务可能另行收费；启用时相关内容会发送到你配置的服务。

## v1.1.0 更新：新消息提醒

- 客户发来新消息时播放本地提示音并显示桌面通知，覆盖后台店铺和隐藏到托盘的主窗口。
- 在 **系统设置 → 通知告警 → 新消息提醒** 中设置总开关、声音、桌面通知及音量，可先试听后保存；默认启用，音量 60%。
- 首次加载历史会话保持安静，同一会话 3 秒内连续消息合并提醒，避免重复扫描导致连响。
- 点击桌面通知打开对应店铺与买家会话；遇到未发送草稿会保留草稿并提示。
- 原有超时未回复提醒继续独立工作。电脑需要运行、联网并保持店铺登录；桌面弹窗和实际发声还取决于 Windows 通知、音量及音频设备。
- 本地验证使用临时数据和模拟闲鱼页面，并实际执行音频播放；不代表已在你的真实店铺验收。官方页面变化可能影响识别，请安装后用另一账号发消息核对。

## 功能

| 功能 | 说明 |
| --- | --- |
| 多店铺同时在线 | 每店独立登录分区、cookie 隔离，不限店铺数，后台也收发消息 |
| 新消息声音与桌面提醒 | 支持后台店铺、提示音音量与试听、点击通知定位会话 |
| 关键词自动回复 | 关键词 / 正则 / 全部消息三种规则，支持排除商品 |
| AI 兜底回复 | 规则未命中时调 LLM，兼容 OpenAI 协议；含议价轮次与底线价控制 |
| 虚拟商品自动发货 | 买家付款后自动发卡密，支持文本 / 图片 / API 取卡，同订单幂等 |
| 商品管理 | 同步在售与已售商品、勾选导入、本地编辑、走官方表单发布 |
| AI 商品文案 | 按关键词生成标题与详情，先预览再采用，不自动发布 |
| 自动续售 | 售罄后自动重新上架，迁移卡密与发货配置 |
| 多客服协作 | 会话分配、人工接管抑制自动回复 |
| 远程协作 | 局域网浏览器查看会话、回复、编辑商品，三级权限 |
| 数据看板 | 店铺 / 商品 / 订单 / 营收 / 卡密统计与趋势图表 |
| 通知告警 | Bark / 钉钉 / 飞书 / 企微 / Telegram / 邮件 / Webhook |

## 技术路线

Electron 壳 + 内置浏览器加载**闲鱼官方网页** + preload 注入。

- 登录由你在官方页面扫码完成，软件**不代存账号密码**
- 消息读取与发送通过页面 DOM 交互实现，**不破解 IM 协议、不调用平台私有签名接口**
- 业务数据主要保存在本机；启用 AI、外部通知、API 取卡或远程协作时，相关内容按配置传输

## 从源码运行

```bash
npm install
npm start
```

需要 Node.js 16+。打包：

```bash
npm run dist
```

## 项目结构

```
src/
├─ main/       主进程：多店铺视图、IPC、托盘、存储、自动发货、AI
├─ inject/     注入官方页面的 preload：消息抽取、发送、商品扫描
├─ shell/      本地界面：渲染层、表格、图表、对话框
└─ remote/     局域网远程协作的浏览器端
scripts/       构建与验证脚本
tests/         单元与回归测试
```
